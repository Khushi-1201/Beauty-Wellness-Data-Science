# Week 5 Submission Bundle
## Predictive Modeling and Algorithm Selection

Files included:
- Week_5_Predictive_Modeling_Algorithm_Selection_Report.docx — report with strategy and measured initial model results
- Week_5_Predictive_Modeling.ipynb — Python notebook for data preparation, visualizations, and model comparison
- Week_5_Model_Comparison_Results.csv — measured MAE, RMSE, and R²
- salon_appointments_dummy.csv — dataset used
- week5_appointments_by_service.png — service booking chart
- week5_appointments_by_weekday.png — weekday booking chart

## How to run
1. Upload the notebook and CSV into the same Google Colab session or place them in the same local folder.
2. Run notebook cells from top to bottom.
3. Confirm the printed metrics match the CSV results.
4. Review limitations before submission.

## Important limitation
The source dataset is synthetic and contains only 100 appointments across one month. The results are educational and preliminary, not proof of real-world predictive accuracy. The dataset has no appointment-status field, so cancellation prediction is not supported.
